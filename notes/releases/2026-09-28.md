> data connection and registration), but the dedicated emergency call isn't implemented yet, so

Unofficial LineageOS 23.2 (Android 16) built from source: MisterZtr's TrebleDroid GSI
(tag v2026.05.24) + this repo's Fold3 fixes built in (`rom/`). **Android security patch 2026-09-01.**
Signed with test keys. Vanilla (no Google apps): flash MindTheGapps yourself.

## New since 2026-09-26
- **Low-brightness flicker fixed, One UI style**: Samsung panels shift colour below 120 Hz when dim.
  Like One UI's "passive" mode, the refresh rate holds at 120 Hz only when the screen is dim in a
  dim room, with One UI's own thresholds per screen (inner ≤ 35 brightness / 50 lux, cover ≤ 84 /
  200 lux); the inner panel's low-frequency drive is switched off in the same conditions.
  Everywhere else refresh stays adaptive 48–120 Hz.
- **AOD refresh 48 Hz** (was stuck at the last rate, often 120 Hz); the panels draw AOD in their
  low-power mode (inner 1–30 Hz, cover 30 Hz).
- **AOD brightness steps like One UI**: follows the light sensor through Samsung's four AOD levels
  (2 / 10 / 30 / 60 nit) instead of always 60 nit on the cover screen.
- **Lock on fold, wake on unfold**: Settings → Display → "Continue using apps on fold" is available,
  default "Never" (locks when folded, like stock). "Swipe up to continue" isn't implemented in AOSP
  and behaves like "Always".
- **Samsung speaker processing**: loads Samsung's audio effects (SoundBooster Plus, SoundAlive,
  Dolby, 3D) from the vendor partition like One UI; loud speaker playback is no longer muffled.
- **Telstra IMS APN built in**: VoLTE works on a fresh install on Telstra/Boost without adding an APN.

## What works (tested on the dev's phone)
- Both screens and switching on fold, outer touchscreen
- Adaptive refresh 48–120 Hz; brightness and auto-brightness on both screens
- Always-on display in Samsung's low-power panel mode: double tap to wake, turns off in a pocket
- Double tap to wake, Flex mode
- All cameras, including cover selfie, ultra-wide and telephoto
- Fingerprint
- **Signal bars**, mobile data, **VoLTE calls, SMS and MMS on Telstra/Boost**
- Wi-Fi, Bluetooth, hotspot, GPS
- Speakers, USB-C headphones
- USB-C dock with desktop mode
- **Android Auto, wired and wireless** (with MindTheGapps)
- RCS (with Magisk + PlayIntegrityFork)

## Known issues
- **Emergency calls**: untested, see the warning above.
- **Clean install not tested yet**: tested by flashing over an existing install (data kept). Please
  report if a fresh install needs extra steps.
- Booting **unfolded** leaves the Samsung logo on the cover screen until the first fold. Boot folded,
  or fold once after booting (OLED image retention).
- VoLTE only tested on Telstra/Boost (see below). Samsung's "Adapt Sound" isn't available.
- Banking apps / Google Wallet tap-to-pay: not supported (unlocked bootloader; Play Integrity BASIC at
  best, and only with Magisk + PlayIntegrityFork).
- Not tested: call waiting / conference, voicemail notification, NFC, eSIM, S Pen.

## Calls on other carriers
- **Mobile data and MMS**: LineageOS's APN list (~4,000 carriers) — very likely fine.
- **VoLTE calls/SMS** use Floss IMS (phh's open-source IMS, patched for Telstra). They need:
  1. an **IMS APN**: built in for Telstra/Boost; others: Settings → Network & internet → SIMs →
     Access Point Names → **+**, APN `ims` (or your carrier's), APN type `ims`, protocol IPv4/IPv6;
  2. VoLTE enabled in your carrier's config: on for Telstra (1345) and Boost (2503) in this build,
     and for ~70 other carriers in LineageOS;
  3. a network that accepts Floss. Untested outside Telstra.
- Calls on networks that still have 3G/2G may work without VoLTE (Samsung's modem), untested.

## Install
**Requirements:** Galaxy Z Fold3 **SM-F926B**, bootloader unlocked, Samsung's final firmware
**F926BXXSJJZH3**, TWRP (see the repo README for unlocking and firmware). The stock vendor
partition is fine; the patched vendor image from older guides isn't needed.

**Recovery (attached): `twrp-q2q-azkali-dynapatch-AP.tar.md5`** is Azkali's TWRP for q2q with
DynaPatch already applied, plus a generic verification-disabled vbmeta. It's the exact recovery
this build was tested with. Flash it in Odin's **AP** slot with **Auto Reboot unticked** (or with
Heimdall: `--RECOVERY recovery.img --VBMETA vbmeta.img` after `lz4 -d`). Then hold **Vol Down +
Power** and, when the screen goes black, **Vol Up + Power** to boot straight into TWRP.

1. Unpack the image on your computer: `xz -d lineage-23.2-20260928-…img.xz` (or 7-Zip on Windows).
   It's already enlarged for Google apps.
2. Reboot to TWRP, then `adb push lineage-….img /tmp/` and
   `adb push MindTheGapps-16.0.0-arm64-….zip /tmp/` (from
   [MindTheGapps](https://github.com/MindTheGapps/16.0.0-arm64/releases)).
3. Install → **Install Image** → the `.img` → **System**.
4. Install → **Install Zip** → MindTheGapps.
5. **Fresh install:** Wipe → **Format Data**. **Updating this ROM:** skip this (data is kept).
6. Reboot. Optional: root with a Magisk-patched **JJZH3** `boot.img`.

Updating from the 2026-09-26 build: steps 2–4 and 6, no wipe.
