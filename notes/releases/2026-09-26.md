# LineageOS 23.2 for Galaxy Z Fold3 (q2q) — first build, 2026-09-26

> ⚠️ **Emergency calls (000/112/911) do NOT work over VoLTE on this build.** On networks without
> 3G (e.g. all of Australia) you **cannot rely on this phone to call emergency services**. Keep
> another phone for emergencies.
>
> ⚠️ **Personal, unofficial build.** Made for and tested on **one** SM-F926B on Telstra/Boost
> (Australia). Things may be broken on your device or carrier. You flash it at your own risk; you
> need an unlocked bootloader (trips Knox permanently) and you can lose data.

Unofficial LineageOS 23.2 (Android 16) built from source: MisterZtr's TrebleDroid GSI
(tag v2026.05.24) + this repo's Fold3 fixes built in (`rom/`). **Android security patch 2026-09-01.**
Signed with test keys. Vanilla (no Google apps): flash MindTheGapps yourself.

## Requirements
- Samsung Galaxy Z Fold3 **SM-F926B** (global/AU), bootloader unlocked
- Samsung's final firmware **F926BXXSJJZH3** (Aug 2026) — boot, vendor and modem stay stock
- Azkali's TWRP for q2q + DynaPatch (see the repo README, "Installing it yourself")

## What works (tested on the dev's phone)
Both screens and switching on fold, outer touch, adaptive refresh 48–120 Hz, brightness on both
screens, auto-brightness, always-on display in Samsung's low-power panel mode (brightness follows
the light sensor, double tap to wake, turns off in a pocket), double tap to wake, Flex mode, all
cameras incl. cover selfie / ultra-wide / tele, fingerprint (kept across reboots), **signal bars**,
mobile data, **VoLTE calls, SMS, MMS on Telstra/Boost** (patched Floss IMS built in), Wi-Fi,
Bluetooth, hotspot, GPS, USB-C headphones, USB-C dock with desktop mode, Android Auto (with
MindTheGapps), RCS (with Magisk + PlayIntegrityFork).

## Known issues
- **Emergency calls**: see the warning above.
- **Clean install not tested yet**: this build was tested by flashing over an existing install
  (data kept). Please report if a fresh install needs extra steps.
- Booting **unfolded** leaves the Samsung logo on the cover screen until the first fold. Boot
  folded, or fold once after booting (OLED image retention).
- VoLTE is only tested on Telstra/Boost. See "Calls on other carriers".
- Banking apps / Google Wallet tap-to-pay: not supported (unlocked bootloader; Play Integrity
  BASIC at best, and only with Magisk + PlayIntegrityFork).
- Not tested: call waiting / conference, voicemail notification, NFC, eSIM, S Pen, a week of use.

## Calls on other carriers
- **Mobile data and MMS**: LineageOS's APN list (~4,000 carriers) — very likely fine.
- **VoLTE calls/SMS** use Floss IMS (phh's open-source IMS, patched for Telstra). They need:
  1. an **IMS APN**: Settings → Network & internet → SIMs → Access Point Names → **+**,
     APN `ims` (or your carrier's), APN type `ims`, protocol IPv4/IPv6. Telstra and Boost need
     this too on a fresh install (not in LineageOS's list yet);
  2. VoLTE enabled in your carrier's config: on for Telstra (1345) and Boost (2503) in this build,
     and for ~70 other carriers in LineageOS;
  3. a network that accepts Floss. Untested outside Telstra.
- Calls on networks that still have 3G/2G may work without VoLTE (Samsung's modem handles
  them), untested.

## Install (TWRP; see the repo README for unlock/recovery)
1. `xz -d lineage-…img.xz` on your computer (the image is already enlarged for GApps).
2. Reboot to TWRP, `adb push lineage-….img /tmp/` and `adb push MindTheGapps-16.0.0-arm64-….zip /tmp/`.
3. Install → **Install Image** → the `.img` → **System**.
4. Install → **Install Zip** → MindTheGapps.
5. Fresh install: Wipe → **Format Data**. Updating this ROM with data kept: skip this.
6. Reboot. Optional: root with a Magisk-patched **JJZH3** `boot.img`.
7. Telstra/Boost VoLTE: add the IMS APN (see above).

Dual-screen switching now works on the **stock** vendor (fixed at boot); the patched vendor image
from earlier guides isn't needed (tested only with the patched vendor so far).
